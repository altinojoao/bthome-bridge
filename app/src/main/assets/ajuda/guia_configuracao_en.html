1 Add a beacon

On the main screen, tap Detect to search for your Shelly BLU Button nearby.

  1. As soon as it appears in the list, tap it to pair it.
  2. Give it an easy name to recognise (e.g. "House keys", "School backpack").
  3. Choose a colour profile to spot it quickly in the command grid.
Each physical beacon only needs to be paired once — it then stays available in the command list.

2 Set up the clicks

Each beacon recognises 1, 2 or 3 clicks — and each one can trigger a different action.

ActionExample use
Run Shelly sceneTurn lights on/off, open blinds
Send notificationLet someone know you've arrived
Ring phone alarmFind a lost phone

Open the command card and assign the desired action to each number of clicks.

3 Enable trip mode

On the command card, turn on "Beacon mode (records trip)". From here on, whenever the beacon is with you, the app records your GPS position periodically.

  • Interval (s) — how often a new GPS point is saved. A low value (e.g. 3-5s) gives more precision; a higher value saves battery.
  • Include location — required for trip mode to work; should always be on in this case.
Without this mode on, the beacon still works normally for clicks/actions, but doesn't build up GPS history — so it can't be used to create trip scenarios.
↑ back to index

4 Record a route

With trip mode on, make the trip as usual with the beacon on you — for example, from home to work.

The app builds up GPS points along the way. This history is the raw material you'll use in the next step to create a scenario — no need to do anything special during the trip, just keep the beacon near you (in your pocket, bag, or car keyring).

The more times you make the same route, the more data you have available to choose the trip that best represents your usual journey.

5 Create a scenario

On the Scenarios screen, create a new one and choose one of the already recorded trips as a template.

  1. Give the scenario a name (e.g. "Arriving home", "Arriving at work").
  2. Choose the actions you want to trigger when the scenario is detected.
  3. The app automatically draws the detection barriers over the chosen route.
↑ back to index

6 Checkpoints and percentage

Each scenario has checkpoints — invisible barriers spread along the route, which the app detects when you cross them, in the right order.

The "Percentage" field sets how far along the route the action should trigger:

  • 50% — triggers halfway through
  • 80% — triggers near the end, useful to prepare something (e.g. turn on the heating) before you arrive
  • 100% — only triggers once the whole route is completed
You don't need to choose the number of checkpoints — the app generates them automatically with enough precision for whichever percentage you choose.

7 Restrict by time

If you only want a scenario to work at certain times, add one or more time windows.

  • Set a start and end time (e.g. 07:00 to 10:00).
  • Choose the days of the week it applies to (or leave blank for every day).
  • You can add several windows to the same scenario — for example, weekday mornings and weekend afternoons.

Outside the configured windows, the scenario won't trigger, even if the route is detected correctly.

8 The real-time map

The trip map automatically follows your current position, like a navigation GPS — no need to move the map around manually.

  • If you drag or zoom, automatic following turns off; tap the recenter button to turn it back on.
  • The compass icon shows a speed and direction indicator.
  • Barriers from active scenarios appear drawn on the map, in the colour of the matching beacon.
↑ back to index

9 Alert if out of range

Turn on this option on the command card to get a warning if the beacon stops being nearby — useful for not forgetting keys, a bag, or other important items.

This option needs "Beacon mode" on to work correctly.
↑ back to index

10 Tips and troubleshooting

The scenario didn't trigger when I arrived: check that the route you took is similar enough to the recorded one, and that the configured percentage isn't too high.

I get out-of-range alerts for no apparent reason: this can happen if the phone goes a long time without processing a signal (e.g. screen locked for long periods) — it usually sorts itself out on the next beacon announcement.

My phone's battery drains faster: try increasing the trip mode "Interval (s)" to record GPS points less often.
